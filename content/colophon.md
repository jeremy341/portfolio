## Type and colour

Geist Mono is a variable font served with the site. The monospace type and dashed hairlines take their cues from a text editor.

The dark Tokyo Night palette uses `--bg` (#1a1b26) for the background, `--fg` (#c0caf5) for text, `--line` (#2f334d) for rules and `--accent` (#7aa2f7) for focus and hover. The same tokens have light-mode values.

## Build and hosting

Astro builds static HTML, with Markdown-it for prose and Shiki for code highlighting. GitHub Actions deploys the build to GitHub Pages. The site has no analytics or tracking scripts.

## Content

I edit the English Markdown in `content/` and the German Markdown in `content/de/`. The next deployment publishes the edits.
